# 工作歌单 · 和弦歌词谱

跑场吉他手视奏用的歌单 PWA：305+ 首歌的和弦级数谱 + 每小节歌词，支持 12 调一键转调、节拍器、全屏视奏、离线使用。

## 功能

- **工作歌单 / 临时歌单**：双列表，临时歌单支持演出顺序拖拽
- **和弦谱**：级数（1-7）记谱，12 个调一键转调，字母/级数双行显示
- **编辑**：改和弦（字母输入自动反推级数）、段落改名/增删/拖拽排序、每小节歌词、段落弹奏备注、歌曲元信息（调/速度/拍号）
- **新增歌曲**：页面直接加歌，自动进入编辑模式；可勾选「忽略级数模式」（复杂/升降调歌曲只显示和弦字母、不显示级数，避免级数换算混乱）
- **忽略级数模式**：详情页「显示级数 / 已隐藏级数」按钮可随时对任一歌曲切换；开启后该歌只显示和弦字母行
- **和弦对照表**：常用进行速查，随转调同步，可自定义
- **节拍器**：Web Audio 精确调度（后台标签页也不断拍），拍号自由输入，点按测速
- **保存到 GitHub**：页面内直接把修改写回仓库 `songs.json`（远程为基底合并，只覆盖本地改过的部分）
- **离线 PWA**：Service Worker 缓存，装到主屏后断网可用；数据文件网络优先、离线回退缓存
- **版本号**：界面右上角与浏览器标签显示应用版本（当前 `v1.0.0`），升版后退出重开即见，便于核对是否吃到最新缓存

## 文件结构

```
index.html      页面
style.css       样式
app.js          全部逻辑（乐理转换 / 渲染 / 编辑 / 保存 / 节拍器）
songs.json      数据：songs(歌曲+元信息) / progMap(级数谱) / sectionNotes / sectionLyrics / tempList
sw.js           Service Worker（离线缓存）
manifest.json   PWA 清单
icon-192.png    图标
icon-512.png    图标
```

## 部署（GitHub Pages）

1. 仓库 Settings → Pages → Source 选 `main` 分支根目录
2. 访问 `https://<用户名>.github.io/<仓库名>/`

## 安卓平板安装

1. Chrome 打开上面的地址 → 菜单 → **添加到主屏幕**
2. 首次联网完整打开一次（让 Service Worker 装好缓存）
3. 之后断网也能从主屏图标打开使用

## 「保存到 GitHub」使用

1. 在 GitHub 生成 Personal Access Token（勾选 **repo** 权限）
2. 页面右上「保存到GitHub」→ 粘贴 Token（可勾选记住）→ 保存
3. 所有页面修改（歌曲/和弦/歌词/备注/对照表/临时歌单）合并写回仓库 `songs.json`

## 开发约定

**改完代码必须升级 `sw.js` 里的 `VERSION`**（如 `songbook-v1` → `v2`），否则用户端 Service Worker 继续吃旧缓存不更新。
